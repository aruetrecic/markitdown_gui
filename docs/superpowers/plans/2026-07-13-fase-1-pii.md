# Fase 1 — Diferenciador de privacidad (PII) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que el usuario vea qué PII se redactó (informe), pueda pedir etiquetas coherentes (pseudonimización `[NOMBRE_1]`…) y redactar términos propios, sin romper los tests actuales.

**Architecture:** Núcleo en `backend/anonymizer.py`: se añade `anonymize_text_with_report(...)` como función central que devuelve `(texto, informe)`; `anonymize_text(text, keys) -> str` queda como wrapper de compatibilidad (así los ~11 tests actuales no se tocan). Cada entregable añade un kwarg con default a esa función (retro-compatible). El cableado en `main.py` propaga el informe y dos `Form` nuevos. El frontend muestra el informe y añade dos controles.

**Tech Stack:** Presidio (`AnalyzerEngine`/`AnonymizerEngine`, operador `custom` para el contador), stdlib `re` (términos literales), FastAPI `Form`, vanilla ESM.

## Global Constraints

- **On-device**, import perezoso de Presidio (no cargar el modelo al importar).
- **Fuente de verdad única:** `ENTITY_CONFIG` (key/entity/label/tag). El tag base de la pseudonimización se **deriva** del `tag` existente (`[DNI]`→`DNI`). No duplicar.
- **Seguridad:** los términos propios son **literales** (`re.escape`, case-insensitive). **Prohibido** regex de usuario (ReDoS en instancia pública). Límite `MAX_CUSTOM_TERMS = 100`.
- **Compatibilidad:** `anonymize_text(text, keys) -> str` mantiene su firma y comportamiento; los tests existentes de `test_anonymizer.py` siguen verdes sin cambios.
- **Suite verde:** `uv run --all-extras pytest`. Lint `uv run ruff check backend/ tests/`, formato `uv run black --check backend/ tests/` (line-length 100; ruff E,F,I,UP,B ignore B008).
- El informe usa las `key` de `ENTITY_CONFIG` (+ key sintética `custom_terms`); solo tipos con conteo ≥ 1.

```python
def anonymize_text_with_report(
    text: str, entity_keys: list[str]
) -> tuple[str, dict[str, int]]:
    """Anonimiza `text` y devuelve (texto, informe) con {key: nº} de las
    sustituciones realmente aplicadas (contadas desde el EngineResult de
    Presidio, ya resueltos los solapes). `entity_keys` son claves de
    ENTITY_CONFIG; las desconocidas se ignoran."""
    keys = [k for k in entity_keys if k in _BY_KEY]
    if not text or not keys:
        return text, {}

    from presidio_anonymizer.entities import OperatorConfig

    analyzer, anonymizer = _get_engines()
    entities = [_BY_KEY[k]["entity"] for k in keys]
    results = analyzer.analyze(text=text, language="es", entities=entities)
    operators = {
        _BY_KEY[k]["entity"]: OperatorConfig("replace", {"new_value": _BY_KEY[k]["tag"]})
        for k in keys
    }
    engine_result = anonymizer.anonymize(
        text=text, analyzer_results=results, operators=operators
    )
    entity_to_key = {_BY_KEY[k]["entity"]: k for k in keys}
    report: dict[str, int] = {}
    for item in engine_result.items:
        key = entity_to_key.get(item.entity_type)
        if key:
            report[key] = report.get(key, 0) + 1
    return engine_result.text, report


def anonymize_text(text: str, entity_keys: list[str]) -> str:
    """Wrapper de compatibilidad: solo el texto anonimizado."""
    return anonymize_text_with_report(text, entity_keys)[0]
```

```python
def _make_counter_operator(tag_base: str):
    """Operador `custom` con estado: cada valor distinto → [tag_base_N]
    consistente dentro de una misma llamada (documento)."""
    seen: dict[str, int] = {}

    def op(value: str) -> str:
        norm = value.strip()
        idx = seen.get(norm)
        if idx is None:
            idx = len(seen) + 1
            seen[norm] = idx
        return f"[{tag_base}_{idx}]"

    return op
```

Helper de redacción literal (case-insensitive, límites de palabra si es alfanumérico):

```python
def _redact_custom_terms(text: str, terms: list[str]) -> tuple[str, int]:
    count = 0
    for term in terms:
        t = term.strip()
        if not t:
            continue
        escaped = re.escape(t)
        # límite de palabra solo si empieza/acaba en carácter de palabra
        pattern = escaped
        if t[:1].isalnum():
            pattern = r"\b" + pattern
        if t[-1:].isalnum():
            pattern = pattern + r"\b"
        text, n = re.subn(pattern, CUSTOM_TERMS_TAG, text, flags=re.IGNORECASE)
        count += n
    return text, count
```

```python
def _parse_custom_terms(raw: str) -> list[str]:
    """'a\nb, c' → ['a','b','c'] (líneas o comas), dedup, tope MAX_CUSTOM_TERMS."""
    parts = re.split(r"[\n,]", raw or "")
    seen, out = set(), []
    for p in (x.strip() for x in parts):
        if p and p.lower() not in seen:
            seen.add(p.lower())
            out.append(p)
    return out[:MAX_CUSTOM_TERMS]
```
